## 一、时间线大事记

### A. NetApp

- 1992年｜David Hitz、James Lau、Michael Malcolm 在硅谷创立 Network Appliance（NetApp 前身），最初规划写在 Hobee 咖啡厅的一张餐垫纸上；当时主要竞争对手是 Auspex Systems｜https://www.sohu.com/a/146204410_776839 、https://baike.sogou.com/v8326142.htm
- 1992年｜创立次年即定下「网络附加存储（NAS）」路线，站在存储与网络的交叉点上；EMC 当时断言「NAS是长不大的孩子」｜https://dzwww.com/it/itxinwen/itfengyun/200208300919.htm
- 约1993年｜向 Tandem Computers 系统管理员 Patrick Mulrooney 出售首台存储系统；该系统启动仅需30秒（对比其他设备数小时）｜https://www.sohu.com/a/146204410_776839
- 1994年1月17日｜Hitz、Lau、Malcolm 三人在 USENIX Winter 1994（旧金山）发表 WAFL（Write Anywhere File Layout）论文《File System Design for an NFS File Server Appliance》，奠定 Snapshot（写时复制、快照）技术基石；WAFL 至今仍是 NetApp 所有存储（含云上 ONTAP）的核心｜https://www.cs.princeton.edu/courses/archive/fall04/cos318/docs/netapp.pdf 、http://portal.acm.org/doi/abs/10.5555/1267074.1267093
- 1994年｜获红杉资本（Sequoia）风险投资｜https://baike.sogou.com/v8326142.htm
- 1995年11月21日｜以 NTAP 为代码在纳斯达克上市（一说1994年上市，为搜狐25周年文内笔误，采信搜狗百科与多源交叉的1995年11月）｜https://baike.sogou.com/v8326142.htm （另见 https://www.sohu.com/a/146204410_776839 「第四年登陆纳斯达克」）
- 1990年代中后期｜雅虎成为首个大客户，数据从零增至超600TB，仅需12名兼职管理员维护；1995–2000年公司年增长率持续超87%｜https://dzwww.com/it/itxinwen/itfengyun/200208300919.htm
- 2000年9月｜正式进入中国设立办事处；中国第一个用户是新浪｜https://dzwww.com/it/itxinwen/itfengyun/200208300919.htm
- 2001年｜NAS 市场首次丢失头名：NetApp 份额由50%跌至35%，EMC 由36%升至45%（Gartner 数据）；EMC 靠把高端 Celerra 搭配 Symmetrix 捆绑销售抢走收入份额｜https://www.information-age.com?p=23477/
- 2002财年｜营收下滑21%至7.983亿美元（其中 NAS 收入5.66亿美元），净利润4250万美元（上年1.164亿）；2001财年营收约10亿美元｜https://www.information-age.com?p=23477/ 、https://dzwww.com/it/itxinwen/itfengyun/200208300919.htm
- 2002年10月2日｜发布 FAS900 系列，首次同时支持 NAS 与 SAN（FC），正式进军 SAN 市场｜https://www.information-age.com/netapp-unveils-integrated-nas-san-device-23457
- 2009年｜推出 FlashCache（闪存缓存）；2010年推混合闪存 FAS；2012年推全闪存产品｜https://www.sohu.com/a/216052317_700450
- 2014年｜2月发布 FAS8000 系列；5月发布首款主打全闪存的 AFF8080 EX（400万 IOPS、单节点可容约4.6PB 闪存）｜https://www.computerworld.com/article/1525027/netapp-unveils-all-flash-shared-storage-array.html
- 2015年6月1日｜Tom Georgens 卸任 CEO，George Kurian 接任｜https://baike.sogou.com/v8326142.htm
- 2015年12月（至2016年1月完成）｜以8.70亿美元收购全闪存公司 SolidFire｜https://baike.sogou.com/v8326142.htm

## 三、标志性事件详解

### 1. WAFL 论文与「快照」的诞生（NetApp，1994）
1994年1月17日，Hitz/Lau/Malcolm 在 USENIX Winter 1994 发表 WAFL 论文。核心贡献有三：①写任意位置（write-anywhere）+写时复制，让写入永远落在新块，配合 NVRAM 保证一致性；②把元数据全部当文件管理，使文件系统可动态扩容（RAID 扩盘后文件系统跟着扩）；③用 CoW 低成本实现 Snapshot，并借此免除文件系统一致性检查。快照后来成为整个存储行业的标配功能。产品雏形是「NFS 文件服务器家电」——专用、易用、30秒启动（对比当时通用服务器数小时的启动配置）。来源：https://www.cs.princeton.edu/courses/archive/fall04/cos318/docs/netapp.pdf 、http://portal.acm.org/doi/abs/10.5555/1267074.1267093 、https://www.sohu.com/a/146204410_776839

### 2. EMC vs NetApp 的 NAS 之战（2001–2007）
1990年代 NetApp 独享 NAS 市场近半壁江山；EMC 起初公开看衰 NAS（「长不大的孩子」），2001年借助把高端 Celerra 文件服务器捆绑进 Symmetrix 安装基座的打法，首次将 NetApp 挑落马下：NetApp NAS 份额一年内从50%跌至35%，EMC 从36%升至45%（Gartner）。2002年 NetApp 营收跌21%至7.983亿美元。NetApp 的反击是2002年发布 FAS900 进军 SAN——公开承认了 NAS/SAN 融合的大势；此后双方在统一存储与 iSCSI 上缠斗多年，IDC 口径2006-2007年 EMC 以38.1%对27.2%保持领先。这场战争的结果是「统一存储」取代单一 NAS/SAN 成为主流形态。来源：https://www.information-age.com?p=23477/ 、https://dzwww.com/it/itxinwen/itfengyun/200208300919.htm 、https://m.zhiding.cn/article/878747.htm 、https://www.information-age.com/netapp-unveils-integrated-nas-san-device-23457

### 3. Pure 的 Evergreen 模式与「存储当订阅卖」（2015）
2015年6月 Pure 发布 Evergreen 订阅，挑战行业惯例的4–5年强制刷新周期：客户「买一次」，通过 Upgrade Flex 换控制器只付差价、旧控制器全额抵扣；SAS 闪存模块可生产状态下热插拔迁移，最终演进到全 NVMe 不迁移数据、不重买已购 TB。该模式成为 Pure 高复购率（超65%）与新客赢单率的核心解释。分析师评价其「CX 是对抗 Dell EMC、NetApp 的清晰差异点」。2026年更名 Everpure，公司名直接取自 Evergreen——订阅模式被写进了公司名字。来源：https://www.purestorage.com/content/dam/pdf/en/analyst-reports/ar-evergreen-storage-is-all-flash-program-to-beat.pdf 、http://blog.purestorage.com/transforming-to-nvme-the-evergreen-way/ 、https://purestorage.com/company/newsroom/press-releases/pure-storage-becomes-everpure.html

### 4. 亚奈的三段人生与 Infinidat 的「反全闪」豪赌（1987–2020）
亚奈职业生涯三部曲：第一段在 EMC（1987–2001），用廉价 PC 硬盘造出 Symmetrix，助 EMC 从 IBM 手中夺下高端存储王座，本人按1%销售分成成为 EMC 最高薪经理；第二段是 XIV（2002–2008），用 x86 网格做网格化存储，被 IBM 收购（约2–3.5亿美元，两说）；第三段是 Infinidat（2011–2020），创业动机颇具戏剧性——在纽约做生物医学博士的儿子抱怨基因测序仪数据量太大、云存储费钱，加上老 EMC 客户的 CIO 们纷纷上门诉苦，年过六十的亚奈第三次出山。Infinidat 押注与全闪行业对着干：用机器学习神经缓存在廉价大容量磁盘上做到媲美全闪的性能（时延低至35µs），单机架数 PB、99.99999% 可用性、毛利率业界罕见。结局却唏嘘：2020年5月被董事长撤下 CEO 之位，随后遭29名员工起诉稀释股份，彻底出局。来源：https://baike.baidu.com/item/莫西·雅奈/8045597 、https://blocksandfiles.com/2026/01/05/infinidat-founder-moshe-yanais-bankruptcy 、https://israeru.jp/business/technology/infinidat/ 、https://www.infinidat.com/es/node/267

### 5. NetApp 的「软着陆进云」：唯一三云第一方（2018–2026）
2018年5月 NetApp 先以 Cloud Volumes Service 试水；2019年6月 Azure NetApp Files GA（与微软联合工程的第一方文件服务）；2021年9月 AWS 发布 FSx for ONTAP，上市3个月即成「AWS 增长最快的存储服务之一」，VMware 把它接为 VMware Cloud on AWS 的主存储；2023年5月 Google Cloud NetApp Volumes 补齐第三块拼图。此后三家云厂商的文件服务市场事实上以 ONTAP 为共同底座。商业回报：FY2026 公共云收入6.88亿美元（剥离 Spot 后同口径+18%），第一方+市场云服务增长30%。2026年 Gartner Critical Capabilities 混合云存储用例第一名、魔力象限领导者，被 NetApp 自我表述为「唯一在三大公有云中内置第一方存储的厂商（the only first-party storage built into AWS, Azure, and Google Cloud）」。客户侧例证：欧洲某航空航天公司绿地项目替换竞品；某亚洲工程公司借 FSx for ONTAP 部署 GenAI 聊天机器人。来源：https://www.architecting.it?p=5380/ 、https://static.netapp.com/v3/assets/blt8710a579a77cafed/blt8c37d4ceafdcb7b4/69eb0498a1ccbffd47cda72a/140167-idc-business-value-amazon-fsx-netapp-ontap.pdf 、https://www.netapp.com/ko/blog/netapp-aws-reinvent-2021-recap/ 、https://s21.q4cdn.com/371534297/files/doc_earnings/2026/q4/generic/q4-prepared-remarks.pdf 、https://www.netapp.com/blog/gartner-leader-for-enterprise-storage-platforms-netapp-blog/
