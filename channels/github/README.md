# GitHub 知识库适配

GitHub 是可追溯、可引用的 Markdown 知识库。通用正文以 `content/published/` 为唯一来源。

本目录只维护：

1. 仓库首页到 `content/100-questions/README.md` 的导航。
2. 已定稿问题编号与正文文件的映射。
3. 发布版本、重要修订和目录变更说明。

不得在此目录保存渠道正文副本。每个已发布主题以 `QNNN` 连接到 `content/published/QNNN-english-slug.md`。
