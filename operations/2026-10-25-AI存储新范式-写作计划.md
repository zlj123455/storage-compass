# 「AI 存储新范式」合集写作计划（v1 · 2026-10-25）

> 定位一句话：**推理时代，存储怎么变——写给 AI 工程师和架构师的前沿分析合集。**
> 与既有合集的关系：存储100问 = 教科书（是什么）；KV Cache 六讲 = 单点深挖（系列课）；本合集 = 新闻分析（正在发生什么 + 怎么选）。

## 一、写法总纲（每篇固定配方）

1. **热点钩子开场**：用一条可验证的新闻/数据切入（铠侠售罄、GTC 发布、信通院 Token 数据），不写空泛导语。
2. **五段式主体**：业务场景 → 核心结论 → 架构/机制 → 关键取舍 → 适用边界。
3. **一图一表**：每篇至少 1 张架构示意图 + 1 张对比表（延续你「表格对比 + 速记卡」的强项）。
4. **硬数据引用**：每篇 ≥2 个带来源的数字（TrendForce / 信通院 / 厂商官方 / 论文），来源链接放文末。
5. **速记卡收尾**：3–5 条一句话结论，方便读者转发摘录。
6. **篇末导流**：三合集互挂——基础概念挂 100 问对应篇，深挖挂 KV Cache 对应讲，下一篇预告。

## 三、发布节奏

- **频率**：每周 1–2 篇（节假日不断更，宁可短篇也不跳票——西瓜哥那 5 年的教训反向验证）。
- **时间**：沿用你现有数据较好的时段；发布后 48h 看首日分享率，<15% 则复盘标题。
- **断更预案**：出差周降级为「速记卡单页」（300字+一张表），保持存在感。
